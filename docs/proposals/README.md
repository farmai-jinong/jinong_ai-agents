# 구조 개선 제안서

프롬프트·매핑 데이터(자가 개선 루프의 allowlist)로는 고칠 수 없는 감점이 남아 루프가 연속으로 개선에
실패하면, 회고 세션이 여기에 제안서를 쓴다(`app/agents/voice_eval/optimize/retro.py`).

**자동 적용되지 않는다.** 5개 케이스와 LLM judge 로 구조 변경을 자동 수락하는 것은 위험하므로,
루프는 제안서만 남기고 멈춘다. 사람이 읽고 채택 여부를 정한 뒤 별도 작업으로 구현한다.

각 제안서 구성: 문제 / 근거(어느 케이스의 어느 감점) / 제안 변경 / 예상 효과(지표) / 리스크·되돌리기.
