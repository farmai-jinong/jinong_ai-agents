# 용어 후보정을 421통화·12,596발화에서 재측정 — 좌표 정정 후 PASS (2026-09-08, 3편)

[1편](./stt-term-fix-calls-2026-09-08.md)은 실통화 84통화에서 FAIL, [2편](./catalog-prescriptions-2026-09-08.md)은
카탈로그 처방으로 PASS 였다. **둘 다 좌표가 틀렸다.** 표본을 5배로 늘리면서 그 사실이 드러났고, 이 문서가
정정본이자 정본이다.

## 0. 정정 — 앞선 두 문서의 base 좌표는 오라클 팔이었다

1·2편은 `deploy-base-k10-jinong` 덤프를 "agents 실경로(base) 좌표" 로 썼다. 그 덤프는 **정답 대본에서 뽑은
bias 목록을 프롬프트에 넣고 디코드한 context-biasing 팔**이다. 근거:

- 그 팔만 맞히고 pass-1 은 놓친 도메인 용어 76건 중 **62건이 그 행의 `bias_positives` 목록 안**에 있다.
  `봉화`←`동화` 처럼 가설 기반 검색으로는 나올 수 없는 것도 들어 있다.
- 공백제거 CER 이 .1402 로 pass-1 .1560 보다 한참 좋다. `stt-041` 이 실측한 실제 레이어 이득은 −.0008 이라
  이 격차(−.0158)를 설명하지 못한다.

그래서 base 용어 recall 이 **.84 로 부풀어** 보였고, 헤드룸이 4배 축소돼 보였다. 진짜 pass-1 좌표에서
**156건 중 101건이 오청**(recall .3526)이다. agents 가 받는 좌표는 pass-1 에 실제 리트리버의 이득(≈0)을
더한 것이므로 **pass-1 이 옳은 근사**다.

판정 기준도 그 좌표 위에서 잡았던 것이라, **다음 세트를 돌리기 전에** 좌표 독립적인 세 축으로 다시 등록하고
커밋했다(`6a60d10`): ① 치환 precision(lenient) ≥ .90 ② 도메인 용어 exact **상승** ③ 공백제거 CER 페어드
CI **상한 < 0**. ②③ 은 첫 판보다 엄격하다.

## 1. 표본 — 421통화 / 12,596발화 / 도메인 용어 741발생

| 세트 | 통화 | 발화 | 도메인 골드 발생 | base pass-1 CER |
|---|---:|---:|---:|---:|
| `jinong-call` (평가 홀드아웃) | 84 | 2,354 | 156 | .1441 |
| `jinong-call-train` (학습 풀) | 337 | 10,242 | 585 | .1427 |
| **합계** | **421** | **12,596** | **741** | |

- 학습 풀은 `md5(audio_id) % 5 != 0`, 홀드아웃의 여집합이고 같은 라벨링 규약(사람 검수 `usable`)이다.
  **base 는 이 통화들을 학습하지 않았으므로** 0-shot 전사로서 유효하다. 챔피언 계열은 암기이므로 여기서
  성적을 읽으면 안 되고, 이 실험은 base 팔만 쓴다.
- 좌표: base `Qwen/Qwen3-ASR-1.7B` pass-1(ctx 레이어 없음). `jinong-call` CER .1441 은 stt-040r 의 base
  pass-1 과 **자릿수까지 같다** — 좌표 재현을 확인한 값이다.
- 골드 자도 새로 만들었다. 덤프 옆 `bias_positives` 는 품종 오탐 46%(`아시`←"아시죠")에 2자 일상어
  (`뿌리`×55·`영양`)를 넣고 실제 상표(`테라도플러스`·`담배거세미나방`)는 놓친다. 대신 **도메인 카테고리
  표제 ≥3자를 정답 대본에 정규화 매칭**하고(긴 것부터 겹침 억제) 사람이 검수한 `gold_denylist.tsv` 5건을
  뺀다. 93통화에서 두 자를 대면 140(bias) vs 156(catalog)이고 catalog 자가 bias 를 완전히 포함한다.

| **도메인 용어 exact 인식률** | .3576 | **.7449** | .7638 | .6100 | 상승 ✅ |

두 세트가 **독립적으로 같은 답**을 낸다:

| 세트 | exact | precision(lenient) | ΔCER CI95 | 판정 |
|---|---|---:|---|---|
| 평가 홀드아웃 84통화(n=156) | .3526 → .7436 | .9509 | −.00834 [−.01112, −.00590] | PASS |

**신뢰도 하한 0.9 가 0.8 을 지배한다** — 5배 표본에서도 같다. 0.8 로 내리면 exact 가 .7449→.7638 로
0.019 오르는 대가로 오탐이 **33→106** 으로 세 배가 된다.

**크기 감각**: `:8105` 후처리 엔진의 실현 이득은 챔피언 좌표 공백제거 −.0012 [−.0020,−.0003] 이었다.
이건 base 좌표에서 **−.00728 [−.00836,−.00628]** — 약 6배이고, CI 가 훨씬 좁다(741발생·12,596발화).
그리고 CER 은 부산물이다. 본론은 **도메인 용어 exact 인식률 .3576 → .7449** 다.

## 3. 정정 2 — 카탈로그 처방의 몫은 생각보다 작다

2편은 "카탈로그 처방이 판정을 뒤집었다"고 썼다. 그건 오라클 좌표에서만 참이다. 그 좌표에서는 base 가
용어를 이미 .84 로 맞히고 있어서 **남은 오탐이 대부분 표기 규약 문제**였고, 그래서 처방이 지배적으로 보였다.
진짜 좌표에서는 오류가 압도적으로 실제 오청이라 LLM 이 처방과 무관하게 고친다. 같은 제안 위에서:

| 처방 | 적용 | TP/이형/FP | lenient | 판정 |
|---|---:|---|---:|---|
| R0 (카탈로그 그대로) | 783 | 646/33/33 | .9537 | **PASS** |
| R1 회사명 접두 87건 | 790 | 653/33/33 | .9541 | PASS |
| R2 원문가드 | 782 | 646/33/33 | .9537 | PASS |
| R3 구멍 보강 9건 | 800 | 660/35/33 | .9547 | PASS |
| ALL | 805 | 666/35/33 | .9550 | PASS |

**R0 만으로 이미 통과한다.** 처방 셋의 순효과는 TP +20, FP ±0 — 해롭지 않고 조금 이롭지만, 판정을 만드는
것은 아니다. 처방은 유지하되(공짜 이득), "카탈로그가 병목" 이라는 2편의 결론은 **좌표 오지정이 만든 착시**다.

## 4. 남은 오탐 33건의 구성

전부 직접 읽었다. 대략 셋으로 갈린다.

- **표제 규약(용어는 맞음, ~1/3)**: `벼룩벌레 → 벼룩잎벌레`×3, `세균성 점무늬병 → 세균점무늬병`×2,
  `건거새미방 → 검거세미밤나방`, `다이젠엔 45 → 다이센엠-45`. 대본과 카탈로그 표제가 다를 뿐이라
  precision .955 는 **하한**이다.
- **진짜 오치환(~2/3)**: `스토풀 → 스톰프`×3, `콩고도 → 콩코드`, `채빈 → 캡틴`(대본은 `세빈`),
  `오버런 → 오베론`(대본은 `웃거름`), `멀티리티 → 멀티히트`.
- **인사말 자리에서 끌려감**: `감사합니다 팜한농 이문자입니다` 같은 상투 인사에서 회사명이 뭉개지면
  LLM 이 그 자리에 상표를 넣는다(`파반동 → 파밤나방`×3, `삼한농 → 새한농`×2). **이름 붙일 수 있는 유일한
  구조적 패턴**이고, 다음에 손댄다면 여기다.

## 5. 그래서

- **`TERM_FIX_ENABLED` 를 켤 근거는 전사 쪽에서 갖춰졌다.** 421통화에서 도메인 용어 exact 인식률이
  두 배 넘게 오르고(.3576→.7449) 치환 precision 은 .955, 공백제거 CER 은 유의하게 개선된다.
  판정 기준은 돌리기 전에 등록했고 두 세트가 독립적으로 재현했다.
- 남은 것은 **비용과 운영 결정**이다: 통화당 LLM 1콜(~22k 토큰, wall +1.5~2초). 켜는 것은 사람 결정.
- 켠다면 `TERM_FIX_MIN_CONFIDENCE=0.9`. 0.8 은 표본 5배에서도 오탐을 3배로 만든다.
- `:8105` 와는 **대체 관계**다. 이 측정은 pass-1 위에서 한 것이고, 2패스 위에 얹는 것은 09-06 실험에서
  이미 더 나빴다.

## 재현

```bash
# ① base pass-1 전사 (jinong_gpu, GPU 2장 ~40분) — 벤치마크 등록은 그쪽 레포 asr_benchmarks.yaml
ssh jinong_gpu 'cd $BASE/tools/model-train && GPU_IDS=1,2 \
  ASR_EVAL_DATA_DIR=$BASE/tools/model-train/data/asr_eval_termfix \
  ASR_EVAL_DUMP_HYP=$BASE/tools/model-train/data/asr_eval_hyp/termfix-base-p1 \
  bash run_asr_eval.sh --model qwen3-asr-1.7b --only jinong-call,jinong-call-train'

# ② 반입 (통화 복원 + 골드) → ③ 후보정 → ④ 처방 분해
python -m app.agents.voice_eval.term_fix.import_calls --dataset jinong-call \
  --dataset-dir tools/model-train/data/asr_eval_termfix/jinong-call \
  --arm base=termfix-base-p1 --gold catalog --out out/tf-p1-eval
python -m app.agents.voice_eval.term_fix --fixtures out/tf-p1-pooled/fixtures --arms pass1 \
  --catalog out/term-fix-tune/catalog-ALL.jsonl --min-confidence 0.9 --reject-catalog-originals \
  --provider gemini --sweep 0.8,0.95 --out out/tf-p1-pooled
python -m app.agents.voice_eval.term_fix.tune --run out/tf-p1-pooled \
  --fixtures out/tf-p1-pooled/fixtures --min-confidence 0.9 --out out/tf-p1-tune
```

산출물: `out/tf-p1-{eval,train,pooled}/`, `out/tf-p1-tune/`. 제안 캐시가 있으면 `--provider fake` 로
LLM 없이 재채점된다.
