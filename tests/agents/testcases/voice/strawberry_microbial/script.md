# 녹음 대본 — strawberry_microbial (미생물 관주 + 연막방제 보고)

| 항목 | 값 |
|---|---|
| 목표 길이 | 3~5분 |
| 화자 | 농장주(최OO, 50대 남성 톤·성실, 배합을 줄줄 읊는 스타일) / 컨설턴트(분류해 주는 톤) |
| 상황 | 3월 수확기. 주간 루틴(미생물 관주) + 새벽 연막방제를 마친 날 통화 |
| 핵심 검증 | **제품 카테고리 판별**(농약 크린캡·다이마이트만 방제이력 / 미생물·비료·칼슘제는 투입 제품), 연막방제=약제살포, 배합량 다수 추출 |

> 심각도 단어("조금 보이기 시작", "군데군데")는 그대로 유지할 것.

---

**농장주:** 선생님, 접니다. 최가네. 통화 되세요?

**컨설턴트:** 네, 사장님. 오늘 미생물 넣는 날이라고 하셨죠?

**농장주:** 예, 오전에 다 넣었어요. 늘 하던 대로 광합성균하고, 그 나머지 세 가지, 네 가지를 각 여섯 리터씩. 물 천 리터에 태워서 세 동 다 관주했어요.

**컨설턴트:** 미생물 4종 각 6리터, 물 1,000리터 기준 3개 동 관주요. 다른 것도 섞으셨어요?

**농장주:** 지금 과일 크는 때니까 비대용 비료를 일 킬로 넣고, 칼슘제도 넣었어요. 그… 플러스칼이라고, 이십삼인가 뒤에 붙는 거.

**컨설턴트:** 플러스칼23이요. 칼슘제 넣으시는 건 잘하시는 거예요, 요즘 팁번 나오는 집 많거든요. 그런데 방제는요? 지난번에 응애 얘기하셨잖아요.

**농장주:** 그래서 오늘 새벽에 연막 돌렸어요. 해 뜨기 전에요.

**컨설턴트:** 뭐뭐 넣고 돌리셨어요?

**농장주:** 응애약으로 다이마이트 넣고, 곰팡이약으로 그… 크린, 크린캡이요. 둘을 같이 넣고, 확산제 이천 밀리 넣어서. 그것도 물 천 리터에요. 세 동 다 돌렸어요.

**컨설턴트:** 다이마이트에 크린캡, 확산제 2,000ml. 네, 그 조합이면 응애하고 꽃곰팡이 둘 다 커버되죠. 지금 발생 상황이 어느 정도인데요?

**농장주:** 꽃곰팡이는 꽃에 거뭇한 게 조금 보이기 시작한 정도예요. 며칠 전부터.

**컨설턴트:** 초기네요. 초기에 연막 돌리신 건 잘하셨어요. 응애는요?

**농장주:** 응애는 그보다 좀 있어요. 잎 뒤 들춰보면 군데군데 있어요. 안쪽 동이 특히 그래요.

**컨설턴트:** 군데군데 수준이면 이번에 눌러놔야 해요. 다이마이트가 알에는 약하니까, 사나흘 뒤에 잎 뒤 다시 보시고 살아 있으면 계통 다른 걸로 한 번 더 가야 합니다. 그때 전화 주세요.

**농장주:** 예, 그럴게요. 아 참, 오늘 낮에 유치원 애들이 체험 왔다 갔어요. 서른 명이나.

**컨설턴트:** 하하, 봄이라 체험 철이네요. 애들이 좋아했겠어요.

**농장주:** 좋아하다 뿐이에요, 밭을 아주 뒤집어 놨지. 다음 주엔 면에서 딸기 축제 한다고 부스도 나가야 하고, 바빠 죽겠어요.

**컨설턴트:** 축제 준비까지, 바쁘시네요. 그래도 미생물 관주는 다음 주에도 거르지 마시고요. 주 1회 루틴 지키는 게 뿌리엔 제일 좋습니다.

**농장주:** 예, 그거는 무슨 일이 있어도 해요.

**컨설턴트:** 네, 그럼 응애만 사나흘 뒤에 확인하고 통화하시죠. 수고하셨습니다.

**농장주:** 예, 고맙습니다. 들어가세요.

## 검증 포인트 매핑 (발화 → 기대 추출)

| 대본 발화 | 기대 추출 |
|---|---|
| "광합성균하고 … 네 가지를 각 여섯 리터씩 … 관주" | 시비(오늘) + [농자재/미생물] 4종 각 6L — **방제이력에 들어가면 오답** |
| "비대용 비료를 일 킬로" / "플러스칼이라고, 이십삼인가" | [비료] 비대용비료 1kg, [비료] 플러스칼23 — **모호 발화→제품명 복원** |
| "오늘 새벽에 연막 돌렸어요" | 약제살포(오늘, 연막방제) |
| "다이마이트 넣고 … 크린, 크린캡이요" | [농약] 다이마이트→점박이응애, [농약] 크린캡→꽃곰팡이병 — **더듬는 발화 fuzzy 매핑**, 방제이력 2건 |
| "꽃에 거뭇한 게 조금 보이기 시작" | 꽃곰팡이병 발생, 단계 1 — `조금/보이기 시작` 힌트 |
| "잎 뒤 들춰보면 군데군데" | 점박이응애 발생, 단계 3 — `군데군데` 힌트 |
| "사나흘 뒤에 … 살아 있으면 계통 다른 걸로" / "미생물 관주는 다음 주에도" | 향후 계획 2건 |
