# 녹음 대본 — strawberry_nursery_disinfect (본포·육묘장 소독 보고)

| 항목 | 값 |
|---|---|
| 목표 길이 | 3~5분 |
| 화자 | 농장주(박OO, 70대 남성 톤·무뚝뚝, 상표명 대충 발음) / 컨설턴트(받아 적는 톤) |
| 상황 | 9월 말 본포 + 육묘장 전체 소독을 마친 날 저녁 보고 전화 |
| 핵심 검증 | 상표명 다수·STT 난이도(다코닐/모스킬/마쿠피카/나노아이/엑설트), 구어 약칭→표준명 fuzzy 매핑, 본포/육묘장 구분, 효과 평가 발화 처리 |

> "나노아이"는 반드시 붙여서 자연스럽게 발음(제품명 나노-I). 심각도 단어("몇 포기", "많이")는 유지.

---

**컨설턴트:** 네, 사장님. 소독 오늘 하신다더니, 다 하셨어요?

**농장주:** 어, 다 했어. 아침부터 종일 했네. 허리가 아주 끊어지는 줄 알았어.

**컨설턴트:** 고생하셨어요. 어떻게 하셨는지 불러 주시면 제가 정리해 둘게요.

**농장주:** 본포는 스물다섯 말 했어. 잎에서 뚝뚝 흘러내리게, 흠뻑.

**컨설턴트:** 25말이면 500리터네요. 뭐뭐 넣으셨어요?

**농장주:** 마쿠피카 한 병 넣고, 나노아이 오십 미리 넣었지.

**컨설턴트:** 마쿠피카 1병에 나노아이 50ml. 본포는 영양 위주로 가셨네요. 육묘장은요?

**농장주:** 육묘장은 약을 섞었어. 다코닐하고, 나방약 모스킬하고. 그것도 스물다섯 말, 미스트로 구석구석 전체 소독했어. 거기도 마쿠피카 한 병에 나노아이 오십 미리.

**컨설턴트:** 다코닐이면 다코닐에이스 말씀이시죠? 액상으로 된 거.

**농장주:** 어어, 그거. 통에 그렇게 써 있더구만.

**컨설턴트:** 네, 탄저 잡는 걸로는 잘 고르셨어요. 육묘장에 탄저 기미가 있었어요?

**농장주:** 어미묘 잎에 까만 점 있는 게 몇 포기 보이더라고. 탄저인지 아닌지는 몰라도 미심쩍어서 미리 친 거지.

**컨설턴트:** 몇 포기 수준이고 의심 단계면 잘하신 거예요. 그 포기들은 이삼일 더 보시고, 점이 번지면 사진 찍어서 보내 주세요. 나방은요?

**농장주:** 나방은 이번에 벌레가 많이 다녔어. 어린 잎마다 구멍이 숭숭 나고, 시커먼 애벌레가 기어다니고. 파밤인 것 같아.

**컨설턴트:** 네, 이맘때 육묘장 파밤나방이 극성이죠. 지난주에 엑설트 치셨다고 했잖아요, 그건 어땠어요?

**농장주:** 엑설트는 그냥 그랬어. 근데 이번 모스킬은 아주 직방이야. 저녁에 가 보니까 벌레가 싹 떨어졌어. 효과 매우 좋아, 이거는.

**컨설턴트:** 오, 그럼 파밤나방엔 모스킬이 잘 듣는 걸로 적어 둘게요. 계통을 번갈아 쓰신 것도 잘하신 거고요.

**농장주:** 그런가. 아 그리고 이번 주에 나락 벤다고 사람을 못 구해서 아주 애먹었어.

**컨설턴트:** 요즘 어디나 일손이 없죠. 콤바인은 부르셨어요?

**농장주:** 불렀는데 삯이 또 올랐어. 작년보다 마지기당 만 원을 더 달래.

**컨설턴트:** 아이고, 기름값 오르니 다 오르네요. 딸기 얘기로 돌아가서, 다음 소독은 일주일 뒤쯤 한 번 더 봐야 하니까 그때 다시 통화하시죠.

**농장주:** 그래, 그럼 되겠네.

**컨설턴트:** 네, 그럼 탄저 의심 포기만 잘 지켜봐 주시고요. 고생하셨습니다, 사장님.

**농장주:** 어, 수고해요.

## 검증 포인트 매핑 (발화 → 기대 추출)

| "다코닐하고, 나방약 모스킬하고" + 컨설턴트 "다코닐에이스 말씀이시죠" | [농약] 다코닐→**다코닐에이스 액상수화제** fuzzy 매핑, 대상=탄저병 |
| "마쿠피카 한 병 … 나노아이 오십 미리" ×2회 | 제품 마쿠피카·나노-I 추출 (STT 난이도 테스트) |
| "까만 점 … 몇 포기 … 미심쩍어서" | 탄저병 **의심**, 단계 1 — `몇 포기` 힌트 + 의심 경고 |
| "벌레가 많이 다녔어 … 파밤인 것 같아" | 파밤나방 발생, 단계 4 — `많이` 힌트 |
| "지난주에 엑설트 … 그냥 그랬어" / "모스킬은 아주 직방 … 효과 매우 좋아" | 엑설트=지난주 살포, 모스킬=오늘·효과 평가. **평가 문장이 content/보고서에 반영** |
| "점이 번지면 사진 찍어서 보내" / "일주일 뒤쯤 … 다시 통화" | 향후 계획 2건 |
