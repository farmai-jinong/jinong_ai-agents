# 녹음 대본 — strawberry_planting (딸기 정식기 종합 상담)

| 항목 | 값 |
|---|---|
| 목표 길이 | 8~10분 (장편) |
| 화자 | 농장주(진OO, 60대 남성 톤·느긋함) / 컨설턴트(차분·꼼꼼함) |
| 상황 | 정식 직후 정기 전화 상담. 정식 결과 보고 + 병해충 3건 + 방제·천적 확인 |
| 핵심 검증 | 수치 분산 발화 통합(정식일·주수·관수·EC/pH), 심각도 구어 표현 3단계 구분, applied 약제→방제이력, 천적=농자재 분류 |

> 발화 속도는 실제 통화처럼 자연스럽게. "어…", "그…" 같은 간투사는 자유롭게 추가해도 된다.
> 단, 아래 [검증 포인트 매핑]의 정보성 표현은 바꾸지 말 것(심각도 단어가 발생단계 판정 기준).

---

**컨설턴트:** 여보세요, 사장님. 안녕하세요, 농업기술센터 상담사입니다. 통화 괜찮으세요?

**농장주:** 아이고 네, 안녕하세요. 마침 하우스에서 잠깐 나온 참이에요.

**컨설턴트:** 지난주에 태풍 올라온다고 해서 걱정했는데, 그쪽은 피해 없으셨어요?

**농장주:** 다행히 비껴갔어요. 바람만 좀 불고 말았지. 옆 동네는 비닐 찢어진 데도 있다던데 우리는 멀쩡해요.

**컨설턴트:** 다행이네요. 그럼 본론으로, 정식은 다 끝나셨죠?

**농장주:** 네, 끝났어요. 십일일에 시작해서… 며칠 걸렸더라, 한 열흘 했나? 아니다, 십구일에 마쳤으니까 아흐레 걸렸네요.

**컨설턴트:** 9월 11일부터 19일까지요. 올해는 몇 주나 들어갔어요?

**농장주:** 어… 동당 만 주씩 여섯 동이니까, 육만 주 들어갔지요.

**컨설턴트:** 육만 주면 작년보다 좀 늘리셨네요.

**농장주:** 한 동 더 지었잖아요. 그나저나 모종값이 올라서 아주 혼났어요. 작년보다 주당 백 원씩은 더 줬다니까.

**컨설턴트:** 요즘 다들 그 얘기 하세요. 육묘장들이 값을 많이 올렸더라고요.

**농장주:** 그러게 말이에요. 내년엔 우리가 좀 키워볼까 싶기도 하고.

**컨설턴트:** 그건 겨울에 한번 같이 계획 잡아보시죠. 물 관리는 지금 어떻게 하고 계세요?

**농장주:** 물은… 아침 여덟 시에 첫 물 주고, 두 시에 마지막 물 줘요.

**컨설턴트:** 하루에 몇 번 나눠서요?

**농장주:** 세 번… 아니다, 지난주부터 한 번 늘려서 네 번 줘요. 한 번에 삼 분씩.

**컨설턴트:** 오전 8시부터 오후 2시 사이에 4회, 회당 3분이요. 활착기니까 적당하네요. 급액 농도는요?

**농장주:** 이씨는 낮게, 영 점 칠로 맞췄어요.

**컨설턴트:** 산도는 확인해 보셨어요?

**농장주:** 피에이치는 육으로 나오더라고요. 육 점 영.

**컨설턴트:** EC 0.7에 pH 6.0이면 활착기 표준 그대로예요. 잘하고 계시네요. 애들 상태는 어때요? 활착은 잘 됐어요?

**농장주:** 대체로 잘 잡았는데, 몇 가지가 걸려요. 그… 시드는 포기가 있어요.

**컨설턴트:** 시들음 증상이요? 어느 정도나 돼요?

**농장주:** 군데군데 있어요. 어제 돌면서 세어보니까 열 포기는 넘던데. 한 동에 서너 포기씩.

**컨설턴트:** 육만 주에 그 정도면 아직 초기지만, 시들음병은 놔두면 옆으로 가니까요. 잎이 낮에 처졌다가 저녁에 도로 서요?

**농장주:** 맞아요, 딱 그래요. 아침엔 멀쩡하고.

**컨설턴트:** 시들음병 맞는 것 같네요. 이병주는 아깝다 생각 마시고 뽑아서 밖으로 내가세요. 뿌리째로요.

**농장주:** 역시 그래야겠지요. 이번 주 안에, 한 이삼일 안에 뽑아낼게요.

**컨설턴트:** 네, 뽑은 자리는 관주 라인 물 튀지 않게만 조심하시고요. 다른 건요?

**농장주:** 탄저도 살짝 보여요. 잎에 까만 반점 있는 게 몇 포기 있더라고.

**컨설턴트:** 몇 포기 수준이면 아직 약 칠 단계는 아니에요. 대신 물 튀면 번지니까 두상관수는 절대 하지 마시고, 며칠 더 지켜보다가 늘면 바로 전화 주세요. 그때 약제 정해 드릴게요.

**농장주:** 알겠어요. 그리고 이게 제일 골치인데, 벌레가 잎을 갉아먹어요.

**컨설턴트:** 어떤 모양으로요?

**농장주:** 새 잎을 여기저기 갉아먹은 자국이 많아요. 잎이 그물처럼 되고. 어제 잎 뒤져보니까 시커먼 애벌레도 몇 마리 잡았어요.

**컨설턴트:** 그거 파밤나방 유충이에요. 이맘때 정식 직후에 꼭 들어옵니다. 피해가 그 정도면 약을 치셔야 해요.

**농장주:** 그래서 실은 벌써 쳤어요. 창고에 캡틴이 있길래, 오늘 아침에 캡틴 천 배로 한 번 돌렸어요.

**컨설턴트:** 캡틴 유제요? 잘하셨어요, 파밤나방에 등록된 약이에요. 천 배면 배수도 맞고요. 어린 유충일 때 쳐야 듣거든요.

**농장주:** 아침에 치고 나오는 길에 보니까 그래도 기어다니는 놈이 있긴 하던데.

**컨설턴트:** 약 친 당일은 그래요. 이삼일 보시고, 그래도 살아 있으면 계통 다른 약으로 바꿔야 하니까 다시 얘기하시죠. 아, 그리고 사장님 천적 신청하셨던 건 왔어요?

**농장주:** 네, 그저께 택배로 왔어요. 이리응애. 봉지째로 여섯 동에 다 넣었어요.

**컨설턴트:** 잘하셨네요. 이리응애 넣으셨으면 앞으로 응애약이나 독한 살충제 치실 때는 저한테 먼저 물어보세요. 천적 다 죽으면 돈만 버리는 거라.

**농장주:** 그래서 캡틴 칠 때도 좀 찜찜하긴 했는데.

**컨설턴트:** 캡틴은 천적한테 비교적 순한 편이라 괜찮습니다. 그건 잘 고르셨어요.

**농장주:** 다행이네. 아 참, 우리 큰애가 다음 달에 장가가요.

**컨설턴트:** 아이고, 축하드립니다! 그래서 요즘 바쁘셨구나.

**농장주:** 식장이니 뭐니 집사람이 다 하는데, 나는 돈만 대지요, 뭐. 하하.

**컨설턴트:** 하하, 원래 그런 겁니다. 그래도 정식 끝내놓고 하시니 다행이네요.

**농장주:** 그러니까 서둘러 심었지요. 아, 그리고 옆집 김씨가 올해 오이를 접고 딸기로 넘어온다는데, 상담사님한테 전화하라고 번호 줬어요.

**컨설턴트:** 네, 언제든 주시라고 하세요. 그럼 정리하겠습니다. 시들음 걸린 포기는 이삼일 안에 뽑아내시고, 탄저는 지켜보다가 늘면 연락 주시고, 파밤나방은 캡틴 친 거 이삼일 뒤에 효과 확인. 맞죠?

**농장주:** 네네, 그렇게 할게요.

**컨설턴트:** 저는 다음 주에 한번 농장 들를게요. 가서 시들음 뽑은 자리랑 애들 활착 상태 직접 볼게요.

**농장주:** 그래 주면 고맙지요. 오실 때 미리 전화 주세요.

**컨설턴트:** 네, 그럼 다음 주에 뵙겠습니다. 결혼식 준비 잘 하시고요!

**농장주:** 예예, 고마워요. 들어가세요.

| "동당 만 주씩 여섯 동이니까, 육만 주" | 정식주수 60,000주 (**곱셈 추론**) |

| "이씨는 영 점 칠" / "피에이치는 육 점 영" | EC 0.7 / pH 6.0 |
| "군데군데 있어요 … 열 포기는 넘던데" | 시들음병 발생, 단계 3(10%미만) — `군데군데` 힌트 |
| "탄저도 살짝 … 몇 포기" | 탄저병 발생, 단계 1(2%미만) — `살짝` 힌트 |
| "여기저기 갉아먹은 자국이 많아요" + 컨설턴트 "파밤나방 유충이에요" | 파밤나방 발생, 단계 4(30%미만) — `여기저기/많아요` 힌트. **농장주는 이름을 모르고 컨설턴트가 명명** |
| "오늘 아침에 캡틴 천 배로 한 번 돌렸어요" | 약제살포(오늘) + [농약] 캡틴 유제→파밤나방·1000배·살포함 → 방제이력 |
| "그저께 택배로 왔어요. 이리응애 … 다 넣었어요" | [농자재] 이리응애(천적) 투입 — **농약 아님** |
| "이삼일 안에 뽑아낼게요" / "다음 주에 한번 농장 들를게요" | 향후 계획 2건 |
