# 녹음 대본 — tomato_harvest (수확기 토마토 담배가루이 방제)

| 항목 | 값 |
|---|---|
| 목표 길이 | 3~5분 |
| 화자 | 농장주(김OO, 40대 남성 톤·시원시원) / 컨설턴트(실무형) |
| 상황 | 8월 폭염 속 수확기. 매일 수확 중 담배가루이가 늘어 아침에 약을 치고 보고하는 전화 |
| 핵심 검증 | 작물 판별(토마토 vs 잡담 속 오이), 수확기 관리 요약, 희소 정보의 통화 기반 보강, 검객 수화제→담배가루이 매핑 |

> 심각도 단어("많이 붙어")는 유지. 잡담의 "오이"는 반드시 **옆집** 얘기로만 발화할 것.

---

**컨설턴트:** 여보세요, 김 사장님. 더운데 고생 많으시죠. 가루이 때문에 전화 주셨다고요.

**농장주:** 네, 안녕하세요. 아유, 하우스가 한증막이에요. 낮엔 사람이 못 들어가요.

**컨설턴트:** 요즘 다들 새벽 작업만 하시더라고요. 수확은 계속 나오고 있어요?

**농장주:** 수확은 매일 해요. 오늘 새벽에도 땄고요. 요즘 하루에 한 백 킬로씩 나와요. 색깔도 잘 나오고 물건은 좋아요.

**컨설턴트:** 백 킬로면 꾸준하네요. 품질 좋다니 다행이고요. 그래서, 가루이는 어떤 상황이에요?

**농장주:** 제가 요즘 아침마다 한 바퀴 돌면서 살펴보거든요. 그저께부터 잎 뒤에 하얀 게 많이 붙어 있어요. 잎을 툭 치면 하얗게 날아올라요.

**컨설턴트:** 툭 치면 날아오르는 하얀 벌레면 담배가루이 맞아요. 여름 수확기에 제일 골치인 놈이죠. 놔두면 그을음병까지 오니까 잡으셔야 해요.

**농장주:** 그럴 것 같아서 오늘 아침에 약 쳤어요. 농약사에서 가루이 약 달라니까 검객이라고 주더라고요. 검객 수화제. 천 배로 아침 일찍 쳤어요.

**컨설턴트:** 검객이면 가루이에 등록된 약 맞습니다. 잘 치셨어요. 대신 가루이는 알이랑 약충이 잎 뒤에 남아서 한 번으로는 안 끝나요. 사흘 뒤에 잎 뒤 다시 보시고, 여전히 날아오르면 계통 다른 걸로 한 번 더 가야 합니다.

**농장주:** 네, 사흘 뒤에 보고 전화드릴게요. 수확 중인데 약 치는 건 괜찮은 거죠?

**컨설턴트:** 그게 중요한데요, 검객 라벨에 수확 전 안전사용기준 있으니까 며칠 띄우고 따야 하는지 꼭 확인하시고 지키세요. 그리고 노란 끈끈이 트랩 있잖아요, 그거 통로마다 좀 더 달아 두세요. 밀도 보는 데도 좋고 잡는 데도 좋아요.

**농장주:** 끈끈이 창고에 있어요. 내일 달아 놓을게요. 아, 그리고 옆집 형님네는 오이 하는데, 거기도 가루이가 왔대요. 온 동네가 난리예요.

**컨설턴트:** 하하, 이 더위에 가루이가 안 오는 데가 없어요. 옆집분도 상담 필요하시면 전화 주시라고 하세요.

**농장주:** 전해 드릴게요. 요즘 경매가는 좀 어때요? 우리 물건 값이 영 신통치 않던데.

**컨설턴트:** 여름 물량 몰릴 때라 그래요. 다음 주부터 휴가철 수요 붙으면 좀 나아질 거예요.

**농장주:** 그 말 믿고 버텨 볼게요. 하하.

**컨설턴트:** 네, 그럼 정리할게요. 검객 친 거 사흘 뒤 확인, 끈끈이 추가, 수확 전 안전사용기준 확인. 이렇게요.

**농장주:** 네, 알겠습니다. 고맙습니다!

**컨설턴트:** 네, 더위 조심하세요, 사장님.

## 검증 포인트 매핑 (발화 → 기대 추출)

| 대본 발화 | 기대 추출 |
|---|---|
| "수확은 매일 해요. 오늘 새벽에도 땄고요" | 수확(오늘) |
| "하루에 한 백 킬로 … 색깔도 잘 나오고" | content: 수확량 100kg 내외·품질 양호 (**희소 메모 보강분**) |
| "아침마다 한 바퀴 돌면서 살펴보거든요" | 병해충 예찰 (팔레트 밖 → 신규 후보 허용) |
| "잎 뒤에 하얀 게 많이 붙어" + 컨설턴트 "담배가루이 맞아요" | 담배가루이 발생, 단계 4 — `많이` 힌트, **증상 묘사→컨설턴트 명명** |
| "오늘 아침에 약 쳤어요 … 검객 수화제. 천 배로" | 약제살포(오늘) + [농약] 검객 수화제→담배가루이·1000배·살포함 → 방제이력 |
| "사흘 뒤에 보고 전화드릴게요" / "끈끈이 … 내일 달아 놓을게요" | 향후 계획 2건 |
| 옆집 "오이" + 동네 가루이 | **작물 오인 함정** — 오이 일지가 생기면 오답 |

## 정답에 새면 안 되는 잡담
폭염·한증막 / 옆집 오이 농가 가루이 소식 / 경매가·휴가철 수요 전망
